# Project Title

### 🌱 EcoWise AI – Personal Sustainability Coach
# 📌 Project Overview

### EcoWise AI is an AI-powered sustainability assistant that helps users adopt eco-friendly habits and make environmentally responsible decisions.

## The system provides recommendations on water conservation, energy saving, waste management, and climate action.

# 🎯 Objectives

### Promote sustainable living.

### Create awareness about environmental conservation.

### Provide personalized sustainability recommendations.

### Support climate action initiatives.

# 🌍 SDGs Covered

### SDG 6: Clean Water and Sanitation
### SDG 7: Affordable and Clean Energy
### SDG 12: Responsible Consumption and Production
### SDG 13: Climate Action

# 🛠 Technologies Used
### Python
### Streamlit
### Groq API
### Prompt Engineering

# ✨ Features
### Water Conservation Advisor
### Energy Saving Advisor
### Waste Management Advisor
### Climate Action Advisor
### Personalized Sustainability Tips

# Conclusion
### Eco Wise AI successfully demonstrates how Artificial Intelligence can support environmental sustainability through personalized and easy-to-understand guidance. 
### By combining Prompt Engineering, the Groq API and Streamlit, the application promotes awareness of water conservation, energy saving, waste management and climate action.
